# ooze

Your Vercel projects, live, in a terminal: who's on each site right now, what's deploying, what's failing, and what it all costs. In the style of [sweep](https://github.com/pdcgomes/sweep) and [haunt](https://github.com/pdcgomes/haunt)'s hauntop, with [badcoffee.dev](https://badcoffee.dev)'s Slime.

ooze is being built. [The design](docs/plans/2026-10-15-ooze-design.md) says what it shows, where each number comes from, and how it signs in.

ooze isn't affiliated with Vercel.
